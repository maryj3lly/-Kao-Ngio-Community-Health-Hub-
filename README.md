# Kao Ngio Community Health Hub

**Digital Tools for Community Assessment & Development in Ban Kao Ngio**

แพลตฟอร์มหลักสำหรับบันทึกข้อมูลชุมชนบ้านเก่างิ้วโดยตรงลงใน Google Sheet

## เครื่องมือในแพลตฟอร์ม

1. แผนที่เดินดิน — บันทึกประเภทจุด พิกัด GPS หมู่บ้าน รายละเอียด และช่องข้อมูลสุขภาพตามหัวคอลัมน์ของชีต
2. ผังเครือญาติ — บันทึกรหัสครัวเรือน/สมาชิก ความสัมพันธ์ วันเกิด (ไม่บังคับ) และหมายเหตุ
3. โครงสร้างองค์กรชุมชน — บันทึกชื่อ/ประเภทองค์กร ผู้ประสานงาน เบอร์ติดต่อ หมู่บ้าน และรายละเอียด
4. ระบบสุขภาพชุมชน — บันทึกรหัสสมมติ ชื่อรายการ ประเภทข้อมูล และรายละเอียด
5. ปฏิทินชุมชน — บันทึกชื่อกิจกรรม วันที่ สถานที่ ผู้รับผิดชอบ และรายละเอียด
6. ประวัติศาสตร์ชุมชน — บันทึกหัวข้อ ช่วงเวลา เรื่องราว และแหล่งข้อมูล
7. ประวัติชีวิต — บันทึกรหัสผู้ให้ข้อมูล ชื่อเรื่อง เรื่องราว และบัญชีผู้บันทึก
8. ข้อมูลครัวเรือน — บันทึกชื่อ/รหัสครัวเรือน หมู่บ้าน จำนวนสมาชิก และรายละเอียด

เว็บไซต์เชื่อมกับแท็บทั้ง 8 ของ [Google Sheet Smart Community Database](https://docs.google.com/spreadsheets/d/1a89ZBrl-tNd-_jeWLY8U-2hgaHJHc6jGqV4NjiXYa3E/edit) โดยเขียนแต่ละฟอร์มลงคอลัมน์ที่ตรงกัน ไม่ใช้แท็บ `Tool Records` แบบเดิม และไม่สร้าง/เปลี่ยนหัวตารางอัตโนมัติ ระบบตรวจชื่อแท็บและหัวคอลัมน์ก่อนอนุญาตให้บันทึก หากโครงสร้างไม่ตรงจะแสดงข้อผิดพลาดแทนการเขียนข้อมูลผิดช่อง

การแก้ไขเขียนทับแถวเดิม ส่วนการลบจะลบแถวข้อมูลนั้นออกจากชีตอย่างถาวรหลังผู้ใช้ยืนยัน แผนที่รองรับการเลือกตำแหน่งบนแผนที่หรือ GPS

## การเข้าใช้ระบบบันทึกข้อมูลจริง

หน้าเว็บหลักแสดงหน้าล็อกอินก่อนเปิดเครื่องมือ: ชื่อผู้ใช้ `admin` และรหัสผ่าน `1234` จากนั้นต้องลงชื่อเข้าใช้ Google ด้วยบัญชีที่มีสิทธิ์แก้ไขชีต เว็บจะเปิดหน้า **ผังเครือญาติ** เป็นหน้าเริ่มต้น และออกจากระบบได้จากปุ่มมุมขวาบน

> **ข้อจำกัดด้านความปลอดภัย:** ข้อมูลล็อกอิน `admin / 1234` ฝังอยู่ใน JavaScript และไม่ใช่ระบบรักษาความปลอดภัย การคุ้มครองชีตอาศัยสิทธิ์ของบัญชี Google ที่ลงชื่อเข้าใช้ ห้ามแชร์ชีตกับสาธารณะ

Google OAuth Client ID เปิดเผยได้ในเว็บฝั่งไคลเอนต์; ห้ามใส่ Client Secret ลงในเว็บสแตติก

OAuth อยู่ในโหมดทดสอบ จึงให้เฉพาะบัญชี Test user ที่ตั้งไว้ใน Google Cloud Console ลงชื่อเข้าใช้ได้ บัญชีนั้นต้องมีสิทธิ์แก้ไขชีตด้วย หากเปิดไฟล์ด้วย `file://` ระบบจะเก็บข้อมูลในเครื่องเท่านั้น ไม่ซิงก์ Google Sheet

> **สิทธิ์ข้อมูล:** จำกัดการแชร์ชีตเฉพาะผู้ได้รับอนุญาต และขอความยินยอมก่อนบันทึกพิกัดหรือข้อมูลส่วนบุคคล/สุขภาพ ใช้รหัสหรือนามสมมติเมื่อทำได้

## ทดสอบและเผยแพร่

ใช้ local web server เพื่อให้ ES Modules ทำงานและแสดงแบบฟอร์มทดลอง ตัวอย่าง:

```bash
python -m http.server 8000
```

หรือเปิดด้วยส่วนขยาย Live Server ใน VS Code จากนั้นเปิด `http://localhost:8000` โดย origin ต้องตรงกับรายการที่ลงทะเบียนใน OAuth Client

สำหรับ GitHub Pages ให้วาง `index.html` ไว้ที่ root ของ repository แล้วเปิด **Settings → Pages → Deploy from a branch** เลือก branch/folder ที่ใช้เผยแพร่

## ความเป็นส่วนตัวและจริยธรรม

พิกัด GPS/บ้านเลขที่ ผังเครือญาติ และประวัติชีวิตเป็นข้อมูลอ่อนไหว ควรขอความยินยอมก่อนบันทึกพิกัดหรือเรื่องเล่าส่วนบุคคล ใช้นามสมมติ/รหัสแทนชื่อจริง และจำกัดผู้เข้าถึงชีต ระบบสุขภาพชุมชนนี้เก็บได้เฉพาะข้อมูลบริการและทรัพยากรภาพรวม ไม่ใช่เวชระเบียน ห้ามบันทึกชื่อผู้ป่วย เลขประจำตัว การวินิจฉัย หรือข้อมูลสุขภาพรายบุคคล

แผนที่ใช้ข้อมูลแผนที่จาก OpenStreetMap และแสดงที่มาในแผนที่ พิกัดที่บันทึกเป็นตำแหน่งละเอียด จึงควรเก็บและเผยแพร่เท่าที่จำเป็น

## ข้อจำกัดของฟอร์มทดลองหน้านี้

- ข้อมูลเก็บในเบราว์เซอร์ปัจจุบันเท่านั้น ไม่ได้ส่งหรือซิงก์กับ Google Sheet
- การเข้าสู่ระบบและบันทึกข้อมูลจริงต้องทำในระบบ Apps Script ที่ลิงก์ไว้ ไม่ใช่จากฟอร์มทดลองนี้
- การใช้งานระบบ Apps Script และสิทธิ์ของชีตขึ้นอยู่กับการตั้งค่าของเจ้าของระบบ
