# Kao Ngio Community Health Hub

**Digital Tools for Community Assessment & Development in Ban Kao Ngio**

แพลตฟอร์มสำหรับเก็บและศึกษาแนวทางข้อมูลชุมชนบ้านเก่างิ้ว พร้อมลิงก์เข้าใช้ระบบ Smart Community 7 Tools ที่เชื่อมกับ Google Sheet

## เครื่องมือในแพลตฟอร์ม

ไฟล์ Google Sheet และระบบ Apps Script พร้อมใช้งานอยู่แล้ว:

- [เปิดระบบ Smart Community 7 Tools](https://script.google.com/macros/s/AKfycbwvnymt6nKdC08qVMP6jo88_8SdxU2i1BeuEY4KbfBP/exec)
- [เปิด Google Sheet Smart Community Database](https://docs.google.com/spreadsheets/d/1a89ZBrl-tNd-_jeWLY8U-2hgaHJHc6jGqV4NjiXYa3E/edit)

1. แผนที่เดินดิน — บันทึกพิกัด GPS/ตำแหน่งบนแผนที่ บ้านเลขที่หรือชื่อสถานที่ รายละเอียด และสัญลักษณ์จุดสำรวจ
2. ผังเครือญาติ — บันทึกรหัสครัวเรือน/สมาชิก ความสัมพันธ์ รุ่น และช่วงอายุ
3. โครงสร้างองค์กรชุมชน — บันทึกกลุ่ม/องค์กร ประเภท บทบาท และเครือข่าย
4. ระบบสุขภาพชุมชน — บันทึกหน่วยบริการ ทรัพยากร และกิจกรรมสุขภาพในภาพรวม
5. ปฏิทินชุมชน — บันทึกกิจกรรม วันที่ สถานที่ และรายละเอียด
6. ประวัติศาสตร์ชุมชน — บันทึกเรื่องราวตามช่วงเวลา พร้อมแหล่งที่มา
7. ประวัติชีวิต — บันทึกเรื่องเล่าตามช่วงวัยโดยใช้นามสมมติหรือรหัส

ฟอร์มทดลองในหน้านี้รองรับการเพิ่ม ดู แก้ไข และนำรายการออกจากการแสดงผล โดยแผนที่เดินดินมีตัวเลือก GPS ปุ่มเลือกตำแหน่งบนแผนที่ และสัญลักษณ์สำหรับบ้าน/ครัวเรือน สมาชิกชุมชน (ใช้รหัส/นามสมมติ) วัด โรงเรียน หน่วยบริการสุขภาพ ตลาด แหล่งน้ำ กลุ่มชุมชน และพื้นที่สาธารณะ ความสามารถเหล่านี้ในหน้าเว็บนี้บันทึกเฉพาะในเบราว์เซอร์เท่านั้น

## การเข้าใช้ระบบบันทึกข้อมูลจริง

หน้าเว็บหลักจะแสดงหน้าล็อกอินก่อนเปิดเครื่องมือ: ชื่อผู้ใช้ `admin` และรหัสผ่าน `1234` หลังเข้าสู่ระบบจะเปิดหน้า **ผังเครือญาติ** เป็นหน้าเริ่มต้น และออกจากระบบได้จากปุ่มมุมขวาบน

> **ข้อจำกัดด้านความปลอดภัย:** ข้อมูลล็อกอินนี้ฝังอยู่ใน JavaScript ของเว็บสแตติกและตรวจสอบในเบราว์เซอร์ จึงไม่ใช่การยืนยันตัวตนที่ปลอดภัยหรือป้องกันผู้เข้าถึงไฟล์/ชีตจริงได้ ห้ามใช้รหัสนี้เพื่อปกป้องข้อมูลอ่อนไหวหรือเผยแพร่ชีตสู่สาธารณะ ต้องมี backend ที่ตรวจสอบบัญชีฝั่งเซิร์ฟเวอร์และกำหนดสิทธิ์ชีตจริงก่อนใช้งานจริง

ระบบ Apps Script และ Google Sheet ที่ลิงก์ไว้เป็นแยกต่างหากจากหน้าล็อกอินนี้; การเข้าสู่ระบบใน Community Health Hub ไม่ได้ยืนยันตัวตนหรือให้สิทธิ์ Google Sheet ทั้งนี้ยังไม่ได้ทดสอบการบันทึกข้อมูลจริงจากบัญชีของผู้ใช้

ถ้าระบบขอเข้าสู่ระบบ ให้ใช้บัญชี Google ที่เจ้าของระบบอนุญาต หากเข้าไม่ได้ ให้เจ้าของชีตตรวจสิทธิ์การแชร์/การ Deploy Web App ไม่ต้องสร้างชีตซ้ำ

ฟอร์มในหน้าเว็บไซต์ Community Health Hub นี้เป็น **โหมดทดลองในเครื่อง** และไม่ซิงก์ข้อมูลไป Google Sheet ปุ่ม **เปิดระบบจริงเพื่อบันทึกข้อมูล** ในหน้าแต่ละเครื่องมือจะพาไปยังระบบ Apps Script ที่เชื่อมชีตจริง

> **สิทธิ์ข้อมูล:** ผู้ใช้ที่มีสิทธิ์ในระบบ/ชีตสามารถเข้าถึงข้อมูลชุมชน รวมถึงพิกัดและข้อมูลที่อ่อนไหว ควรจำกัดบัญชีที่แชร์และขอความยินยอมก่อนบันทึก

## ทดสอบและเผยแพร่

ใช้ local web server เพื่อให้ ES Modules ทำงานและแสดงแบบฟอร์มทดลอง ตัวอย่าง:

```bash
python -m http.server 8000
```

หรือเปิดด้วยส่วนขยาย Live Server ใน VS Code จากนั้นเปิด `http://localhost:8000` ระบบบันทึกจริงเปิดผ่านลิงก์ Apps Script ได้โดยไม่ต้องตั้ง OAuth Client ID ให้หน้า prototype นี้

สำหรับ GitHub Pages ให้วาง `index.html` ไว้ที่ root ของ repository แล้วเปิด **Settings → Pages → Deploy from a branch** เลือก branch/folder ที่ใช้เผยแพร่

## ความเป็นส่วนตัวและจริยธรรม

พิกัด GPS/บ้านเลขที่ ผังเครือญาติ และประวัติชีวิตเป็นข้อมูลอ่อนไหว ควรขอความยินยอมก่อนบันทึกพิกัดหรือเรื่องเล่าส่วนบุคคล ใช้นามสมมติ/รหัสแทนชื่อจริง และจำกัดผู้เข้าถึงชีต ระบบสุขภาพชุมชนนี้เก็บได้เฉพาะข้อมูลบริการและทรัพยากรภาพรวม ไม่ใช่เวชระเบียน ห้ามบันทึกชื่อผู้ป่วย เลขประจำตัว การวินิจฉัย หรือข้อมูลสุขภาพรายบุคคล

แผนที่ใช้ข้อมูลแผนที่จาก OpenStreetMap และแสดงที่มาในแผนที่ พิกัดที่บันทึกเป็นตำแหน่งละเอียด จึงควรเก็บและเผยแพร่เท่าที่จำเป็น

## ข้อจำกัดของฟอร์มทดลองหน้านี้

- ข้อมูลเก็บในเบราว์เซอร์ปัจจุบันเท่านั้น ไม่ได้ส่งหรือซิงก์กับ Google Sheet
- การเข้าสู่ระบบและบันทึกข้อมูลจริงต้องทำในระบบ Apps Script ที่ลิงก์ไว้ ไม่ใช่จากฟอร์มทดลองนี้
- การใช้งานระบบ Apps Script และสิทธิ์ของชีตขึ้นอยู่กับการตั้งค่าของเจ้าของระบบ
